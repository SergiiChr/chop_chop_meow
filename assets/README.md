# Prototype sprite sheets

Art direction option 2, smooth illustrated sprites, is selected for the playable prototype. The current sprite sheets were generated with the built-in image generation tool for this project; no external copyrighted game art or third-party sprite packs are used. They are prototype assets and may need cleanup or replacement before release.

Generation prompts are preserved in [PROMPTS.md](PROMPTS.md) and [animations/PROMPTS.md](animations/PROMPTS.md).

`world-atlas.png` is 1448 × 1086 px and is consumed as a 4-column × 3-row sheet (362 × 362 px cells). Its cells cover the world objects used by `WorldView`: tree, stone, iron/loose iron, coal, berries, basic furnace, reinforced furnace, hut, chest/recovery box, anvil, signpost, and campfire. `travel-atlas.png` is 2172 × 724 px and is consumed as three 724 × 724 px cells for wolves, trade carts carrying goods, and returning payment.

Sixteen named WebP animation atlases are loaded from `data/animations.json`. Fifteen clips have four directions × eight frames; the unarmed player punch has seven frames per direction, for 508 frames total. The set includes player and worker walking, dedicated hand-gathering clips, player and worker iron axe and pick use, player steel axe and pick use, player and worker hammer and bellows work, worker crate carrying, and the player punch. The player and worker retain distinct illustrated skins. Player tool actions use the carried tool; worker actions use movement and an explicit transient work-state enum. The `WorkState` property is excluded from saves and is recomputed by the simulation.

The runtime reads authored rectangular regions and foot pivots from `data/animations.json` and creates `AtlasTexture` regions. The offline layout source is `art/animation-layouts.json`; `tools/bake_animations.py` packs exactly those rectangles and preserves every RGBA pixel inside them, including disconnected tools. It does not scan pixels or infer anchors. Thirteen older source sheets are recovered from the pinned Git revision `9d167ab`; three additional lossless source sheets live in `art/animation-sources/`, which Godot ignores. To rebake art, install the optional development dependency with `python -m pip install -r tools/requirements-art.txt` and run `python tools/bake_animations.py`. Pillow is not needed to play, set up, test, or export the game. The export excludes `art/`, `docs/`, and `tools/`. See the [runtime animation preview](../docs/screenshots/animations.gif).

The refinement adds `worker-atlas.png` (4×2 directions/walk poses), a separate skin with blue bib overalls, cream work shirt and empty hands. `environment-details.png` has two equal cells: a natural pond and a hut with an adult-sized doorway. `item-atlas.png` is a 4×3 sheet for hotbar inventory icons (axe, pickaxe, steel tools, iron, steel, wood, stone, iron ore, coal, berries, water, empty). All were generated with the built-in image tool using the existing artwork as reference.

Scale is anchored to an 85 px adult actor. The renderer uses smaller waist-height chests/anvils and knee-height resource piles, a doorway sized for the actor, and trees about four people tall. The pond art is scaled to a 4.5-tile walkable radius. Sprite hit regions use the same dimensions as drawing. Hut placement and collision use a larger footprint. Grass is a tiled, seamless noise texture generated at runtime, with broad subtle patches and a narrow worn trail on top. These refinements change fresh-map placement while preserving existing saves.

`ui/` holds hand-written SVG toolbar icons: hammer (build), backpack (inventory), hard hat (workers) and open book (guide).
