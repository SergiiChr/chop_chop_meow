# ProtonScatter placement bake

`placements.json` is a fixed-seed, offline placement bake generated by HungryProton's ProtonScatter addon.
The game loads the committed JSON; the addon is only needed to regenerate it.

`tools/scatter.py` downloads the pinned source archive and verifies its SHA-256.
It extracts only `addons/proton_scatter` into the ignored `.tools/scatter` cache and imports it in an isolated Godot project.
It then runs the real ProtonScatter modifier stack from `tools/bake_scatter.gd`.

The bake holds 40,000 candidate transforms over a 216 by 216 world-space box centered at `(108, 108)`.
The JSON `points` rows are `[x, z, yaw, scale]`, with yaw in radians.
The bake has no terrain or gameplay masking and creates no scene instances.

The game filters the points at load.
It drops wet ground, the clearing, the cart trail, resource footprints and mine approaches.
It then builds six shared MultiMeshes: meadow patches, ferns, ordinary bushes, flowers, pebbles and twigs.
The forest fixture ends up with 7,600 meadow patches, 331 ferns, 269 bushes, 183 flowers, 60 pebbles and 35 twigs.
These are decorative; resource trees and berry bushes keep their simulation positions and gathering rules.
A shared disturbance texture also clears plants around placed buildings, mine approaches and the cart trail, and shades worn soil on native terrain.
It updates only when the world layout changes.

Rebuild from the repository root with:

```sh
./tools/scatter.py
```

This fixture freezes the simulation at daylight, hides the interface and fog, and uses a fixed camera and zoom.
