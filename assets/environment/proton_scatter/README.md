# ProtonScatter placement bake

`placements.json` contains a fixed-seed, offline placement trial generated by
HungryProton's ProtonScatter addon. `tools/scatter.py` downloads the pinned
source archive, verifies SHA-256, extracts only `addons/proton_scatter` into the
ignored `.tools/scatter` cache, imports it in an isolated Godot project, and
runs the real ProtonScatter modifier stack from `tools/bake_scatter.gd`.

The bake requests 40,000 candidate transforms over a 216 by 216 world-space
box centered at `(108, 108)`. The JSON `points` rows are `[x, z, yaw, scale]`;
yaw is in radians. The bake contains no terrain or gameplay masking. Consumers
must mask water, trails, structures, and other forbidden areas. It creates no
scene instances and the game does not require the addon at runtime.

Rebuild it from the repository root with:

```sh
./tools/scatter.py
```

The archive URL is `https://codeload.github.com/HungryProton/scatter/zip/7198cc00078ebde61307578137c3f35223c6e438`
and its SHA-256 is
`485295fa4a97cb54bcd20d1b1304ed8a2fc0b28fe3215a07be62d26df9208d5f`.
The baked JSON records the same immutable source commit. `LICENSE` contains the
