# Sprite generation prompts

Generated with the built-in image generation tool, with transparent background requested. The illustrated direction board in `docs/art/illustrated-sample.png` was the style reference for the world and player atlases. The world atlas was the reference for the travel atlas. The committed PNGs are consumed directly; no image service is used when building or playing.
