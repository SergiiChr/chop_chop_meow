# Chop Chop Meow

An isometric woodland survival and production prototype. Gather nearby materials, build a small settlement, craft parts and tools, pack steel tools into crates and sell them, then hire workers to automate resource gathering and furnace work, alone or with up to three friends at home or over the internet. The world is rendered in 3D with code-built low-poly models under an orthographic isometric camera: natural woodland, modern DIY buildings and readable silhouettes. Hotbar and toolbar icons are the original illustrated set; the earlier 2D art directions are kept in [docs/art](docs/art/README.md).

## Run on Linux

From the project directory:

```sh
./build.py play
```

The launcher keeps Godot 4.7.2 .NET, .NET 10, import files, export templates, and build output under `.tools/` and `build/`. First-time setup downloads missing tools and needs internet access. To use an installed Godot 4.7.2 .NET binary, set `GODOT_BIN=/path/to/godot`. Interactive play needs a Vulkan-capable graphics driver; the project uses Godot's Forward+ renderer, which picks a discrete GPU over an integrated one by itself.

```sh
./build.py setup    # prepare local tools, compile C#, and import assets
./build.py editor   # open the Godot editor
./build.py test     # run headless simulation and input/UI checks
./build.py build    # test, export, and smoke-test build/ChopChopMeow.x86_64
./build.py lint     # verify C# formatting and compile
```

`build` also produces `build/ChopChopMeow-linux-x86_64.tar.gz`. Extract it and run `ChopChopMeow/ChopChopMeow.x86_64`; keep the adjacent `.pck` and runtime folder together. The bundle includes the .NET runtime and does not need the SDK. The extracted bundle is smoke-tested without the development SDK in its environment.

Play accepts Godot arguments after `--`. `--showcase` loads a populated review fixture instead of a fresh game; `--showcase --wolves` adds a night ambush to that fixture; `--showcase --lunch` shows the crew at lunch with the worker overview open; `--screenshot /tmp/chop.png` captures the running view after startup and exits:

```sh
./build.py play -- --showcase --screenshot /tmp/chop-chop-meow.png
```

For animation review, `--animation-review` shows every actor action on rotating rigs and `--animation-capture /tmp/directory` captures its frames for visual inspection:

```sh
./build.py play -- --animation-review --animation-capture /tmp/chop-chop-meow-animation
```

These options are developer review tools; they do not represent a normal fresh-start playthrough.

The game opens on a start menu with Continue (the most recent save), New game, Load game, Join game, Options and Quit. There are three save slots and a separate autosave written every 5 minutes. Options holds a window resolution picker and a frame rate limit (off, 60 or 90 fps); the choices are stored in `settings.cfg` and applied at launch.

The launcher keeps its Godot user-data directory under `.tools/xdg-data`; launcher-managed saves are in `.tools/xdg-data/godot/app_userdata/Chop Chop Meow/` as `settlement.json` (slot 1), `settlement-2.json`, `settlement-3.json` and `autosave.json`. A manually exported or otherwise normally launched Godot build uses Godot's standard per-user application-data location instead.

## Multiplayer

**Host** in the pause menu opens the current game to others on UDP port 24565; the pause menu then shows the port and the number of guests, and the game no longer pauses while a menu is open. **Join game** on the start menu, or **Join** in the pause menu, opens a popup with the port already filled in and the address of the last game joined. Join is unavailable while hosting, since it would drop the guests. Up to three guests can join.

The host keeps the world and saves it as usual; guests are not kept in the host's saves. Each guest keeps its own player (position, health, needs, backpack, hotbar, crafting queue and carried crates) on its own computer, one file per host address. Leaving takes the player back from the host, so nothing in flight is lost or kept twice; in between it is saved a couple of seconds after it changes, and on F5. A guest cannot save or load the host's world. A guest that joins for the first time, or whose save is missing, broken or does not fit the host's world, starts with an empty backpack at the clearing. Leaving, or losing the connection, returns a guest to the start menu.

Everyone shares the world, the market and the workers. Sleep needs every player inside a cabin with enough food and water. Night wolves hunt each player separately. Ten times a second the host sends each guest only what changed since the last update that guest confirmed, usually a few hundred bytes, so it plays over the internet as well as at home. Limitations: a guest's actions on items and buildings wait one round trip to the host (walking does not); the host's port must be reachable, as there is no address discovery or NAT traversal; hiring is paid by whoever hires, while daily wages come from the signpost wage slot and then the host's backpack; and the host trusts what a guest's save and position reports say, so play with people you trust.

## Controls

| Input | Action |
| --- | --- |
| WASD or arrow keys | Move in screen directions |
| Shift while moving | Sprint 1.6× as fast; food and drink drain 1.7× as fast; not under 15% food or drink |
| Hold right mouse button on a resource | Approach and gather while held |
| Hold right mouse button on a placed crate | Walk over and pick it up with its contents |
| Left mouse button | Select a resource, building, crate or worker; place selected building; clicking a cabin walks you inside; on open ground, use the item in hand (swing a tool or torch, eat, drink) |
| E | Inspect the selected object if nearby, otherwise the nearest nearby object |
| B | Open building plans |
| I | Open backpack |
| C | Open the crafting menu |
| Tab | Open or close the field guide |
| 1–9 or click a hotbar slot | Put that slot in hand, shown with an outline; building plans and crates go straight to placement; defaults: axe, pickaxe, chest, campfire, furnace, anvil, crafting bench, berries, water |
| Space | Swing axe, or pump the selected nearby reinforced furnace |
| F5 / F9 | Quick save / load to the current slot; until a slot is chosen they open the save or load screen |
| Escape | Cancel placement/assignment, close a panel, or open the pause menu with goals, save, load and options |
| Mouse wheel | Zoom |
| Click / Shift-click an inventory cell | Move one stack / every unit of that item |
| Drag a cell | Move its stack to another inventory or a station input slot; drop an item or building plan on the hotbar to assign it |

The bottom bar holds icon buttons for building (hammer), the backpack, crafting (chisel), workers (hard hat) and the field guide (book), next to the hotbar. Worker assignment starts from worker management; select a resource to assign a gatherer. Assigning a building job to a furnace enables material hauling and operation, with one worker on the bellows and any others hauling. The workers button opens an overview with each worker's daily pay and the total above.

Health, hunger and thirst are a heart, a stomach and a water droplet next to the clock; each empties as its level falls and its outline turns red at 25% or less. A hit flashes red along the screen edges, and they pulse faintly while food or drink is under 15%. A full stomach lasts one in-game day and a full droplet half a day; a day lasts 14 minutes. Coins are a backpack item that stacks to 1000; purchases and hiring are paid from carried coins, wages from the signpost's wage slot first and then carried coins, sale proceeds arrive in the wage slot and overflow into the market output, and coins go into the recovery box on death like any other item. Health, carrying capacity, and daily wages are also shown in Inventory. Stations show one box per recipe input and output, each holding a single stack of 64, with the item's icon above the box and a progress bar between them. Click a backpack item to fill its input box, or drag it in; click or drag a box to take its contents back. Right-click a stack to pick up half of it, then left-click a slot to drop it there. A dropped stack that does not all fit fills the slot and the rest stays held until you drop it elsewhere or click somewhere it cannot go. Inventories are grids of slots and every item stacks to 64 except coins (1000), packed crates (1) and water bottles, which take a slot each unless they are in a crate: the backpack has 24 slots, chests 5, and a worker carries one stack of up to 5. Clicking food or water in the backpack consumes one, clicking a torch lights it and clicking a crate starts placing it; raw food such as raw meat or wheat says it needs cooking first. What each food restores is set per item in `data/game.json`. Building plans are an icon grid; hovering a plan shows its description and what it still needs. Assign hotbar slots from **Inventory → Assign hotbar slots**. Slots reference carried items or building plans; they are not extra storage. Consumable slots use one item, building slots enter placement, and tools select a working reference. A selected raw-material stack can be deposited by clicking a nearby chest. Hotbar assignments persist in saves.

## What the prototype includes

Death drops your backpack in a recovery box and respawns you at the clearing after 30 seconds; emptied boxes disappear and workers never use them as storage.

Wolves hunt at night and run nearly as fast as you; they come out of the dark beyond what you can see, never on screen. A burning campfire keeps them away, and a wolf already chasing you follows you into its light for a few seconds; one log burns about 4 in-game hours. A torch burns just as long, once. With a torch in hand, the first left click on open ground strikes flint and steel for 2 seconds to light it; after that each click swings it, which briefly widens its light by a fifth. Swinging four times within 2 seconds, as fast as swings go, puts it out with a message; relighting takes the same 2 seconds and keeps the burn time it had left. While it burns, a lone wolf still creeps in slowly, but a swing toward it scares it into following you at the edge of the light. More wolves gather over time, and once five are around you they attack together and swings no longer scare them. A direct hit with the torch hurts a wolf and sends it running for a moment. Cabin windows glow but do not deter wolves. Click a cabin to step inside, even while walking: wolves back off at once and give up once out of sight, and you stay in until you press Step outside in its panel. After dying you wake inside the cabin nearest to where you fell, or in the clearing without one. You can sleep until dawn only if your food and water will last until morning; otherwise the sleep button explains why. At half health or less, away from fire and shelter, a nearby wolf leaps for your throat: you are pinned and cannot move or fight, the rest of the pack runs in to feed, and you die within seconds. A wolf kill destroys all food in the recovery box; the pack keeps feeding until you respawn. A slain wolf falls over and leaves a carcass that lasts until it is butchered: hold right mouse on it for 4 raw meat. Sear 2 raw meat into 2 burnt steaks at the stone furnace (Sear meat recipe, one fuel per batch); raw meat cannot be eaten. The starter goal chain in the pause menu (Esc) is a tutorial. Below it are the end goals: a working mine on every ore found in the cliffs, and 1300 coins profit a day for 7 days in a row, where profit is the coins from sales that came back that day minus the wages charged at the next dawn. Reaching both shows an ending screen with Restart and Keep playing.

The opening progression covers hand gathering, construction, food and water, day/night, shelter, mining, iron and steel production, village trade, and worker hiring. The basic furnace accepts wood or mined coal as fuel. The reinforced furnace uses mined coal only and requires heat from manual or worker-operated bellows; below the clear bar it keeps burning coal without making steel. Anvils only work while someone stands at them hammering. Charcoal production is not implemented, and charcoal cannot substitute for mined coal.

A mine is marked for free from the building plans: the plan snaps to a rock spur past the seaward end of the nearest ore cliff and shows a see-through green outline, and each cliff takes one mine. Clicking the mine shows its three stages. A worker with a pickaxe digs the entrance in about one working day; then 50 wood, 10 iron bars and 50 stone go in, hauled from storage by assigned workers or delivered from the backpack; then a worker with a hammer fits the timber frame and the rails, which run into the dark tunnel, in another working day. Workers take the pickaxe and hammer from a tool station. A finished mine takes up to 3 workers with pickaxes, who mine out of sight underground: the cart goes underground with them and the lantern on the frame lights the area like a torch; when nobody is working the cart stands outside, loaded once there is output. Each miner brings out one ore and one rock every 1.6 seconds, about half what a worker gets from a deposit, but a mine never runs out. Output fills two slots, ore and rocks, of one stack each. When either is full, mining stops and a miner carries the full stack out to the nearest storage that takes it; with none, a corner message says the mine is full with no output available.

Crafting has two places. The crafting menu (C) works on the go at base speed, about 10 seconds a recipe, and queues up to eight recipes; clicking a queued one cancels it and returns its materials. Recipes are grouped into boxes by the tool they need, with that tool's icon on the box corner, red while you carry none. A stone chisel takes 2 stone and no tool. With a chisel you carve planks (1 wood → 4), wood parts (1 wood → 2), a wooden mallet and torches (3 wood). The crafting bench costs 10 planks, works twice as fast and must be worked like the anvil, by you or an assigned worker. It has a chisel slot and a hammer slot, and a slotted tool's speed multiplies its rate. It makes everything the menu makes plus crates (6 planks, hammer), the steel axe, pickaxe and hammer, a steel chisel (1 steel part + 1 wood part) and a rake (1 steel part + 2 wood parts), all with any hammer. Some recipes need a better tool: tin cans (1 tin bar → 4) need a steel hammer, and a mortar and pestle (3 stone, by hand or at the bench) needs a steel chisel. A better tool always does a plainer tool's work; the steel chisel works twice as fast as the stone one. A pale grey cliff further inland holds tin: mine it with a pickaxe and smelt 2 tin ore into a tin bar at the stone furnace. The anvil turns one steel bar into one steel part. A small steel tool such as a hammer takes 1 steel part and a big one such as an axe or pickaxe 2, plus 1 wood part for the handle.

A wood crate holds 12 items in total, as one stack or as single items, and its slots grow and shrink with its contents. Place one from the backpack or hotbar, click it to open it, and hold right mouse on it to pick it up with its contents packed inside. Workers never use crates. Putting a crate inside a crate asks first; saying yes ends the game.

The tool station (8 planks, 4 stone) is a rack that holds only tools. Workers need tools for some jobs: an axe to chop wood, a pickaxe to mine ore and coal, a rake to rake leaves. A worker without one walks to the nearest tool station, takes the best tool of that kind and works at its speed, and puts it back when reassigned or when heading home at dusk. If there is none, the worker waits, the corner message says once what they need, and they carry on as soon as one is put in. Stone, berries and loose coal need no tool. Oaks drop a patch of leaves beside the trunk; rake them with a rake (2 wood parts and 1 steel part at the bench) and they fall again every day.

The cooking table (2 steel bars, 6 stone, 8 planks) is a steel grill over a stone firebox with a plank counter and a mortar slot. With a mortar and pestle slotted and someone working it, it crushes 4 berries into 4 crushed berries and grinds wheat into flour; you can do both by hand from the crafting menu with a carried mortar. Its other recipes cook on their own: 2 crushed berries into jam and 1 water + 1 raw meat into meat stew, each over one wood or coal, while 1 flour + 1 water knead into dough with no fire. Each dough bakes into 4 bread at the stone furnace. The canning station (2 steel bars, 8 planks) seals meat stew, jam or raw meat into a tin can over one wood or coal; canned meat stew is the best food to sell. Both stations, like the stone furnace, have a button to switch between wood and coal.

A pile (8 wood) is a 3×3 yard for one resource, holding 14 stacks that build up as a 9-4-1 pyramid in the colour of what it holds. The first resource put in sets it: from then on workers store and take only that, and anything else is refused. Emptying it frees it again. Piles are walkable and snap edge to edge to a pile beside them, so they line up in neat grids. Ticking **Compost** on an empty pile makes it take leaves, grass and any food, cooked, raw or half-made, and turn 4 of them into 1 fertilizer every in-game hour; workers bring leaves and grass to it first, food only when no other storage takes it, and can take the fertilizer out.

A farm plot (8 wood) looks like an empty pile and snaps edge to edge with piles and other plots. Put 1 wheat seeds and 1 fertilizer in it and it sows itself: the soil darkens, and over 3 days small green straws come up, grow into tall green plants and turn into yellow wheat. Hold right mouse on a ripe plot to harvest it by hand, no tool needed; an assigned worker also harvests, and everyone adds to one shared progress, so you can stop and come back. A harvest takes one worker about 1 working day and gives 4 wheat, 2 wheat seeds and 1 grass into the plot. An assigned worker carries out the wheat and grass, keeps 2 seeds in the plot, brings fertilizer and seeds from storage, and sows again. Wheat seeds and fertilizer can also be bought from the village.

The village signpost has three icon buttons: Market, Workers and the price sheet. The market works like a station with six unlabeled input boxes and six output boxes. It only takes crates, and only of raw meat, burnt steak, berries, bread, berry jam, meat stew, canned jam, canned meat stew, or steel axes, pickaxes and hammers; a sale pays for the goods and the crate. Load crates, press Sell, and a cart takes them to Bramblewick and returns 30 seconds later with the coins. They fill the wage slot first, a single stack of up to 1000 coins between the input and output boxes, and the rest goes into the output boxes. Daily wages are paid from the wage slot first and then from your backpack; the slot only holds coins, and you can move coins in or out by hand. The price sheet opens to the left of the panel and lists sell and buy prices with a Buy button for what the village sells: single steel tools, canned food and water by the crate of 12, and wheat seeds and fertilizer by the crate of 4. Bought goods also arrive in the output boxes. The sheet only shows sale prices as last heard from the village and says how many days old they are: it updates when a cart returns, or when a worker assigned to the signpost is sent to fetch fresh prices (a one-time errand down the road and back). Selling lowers an item's price unit by unit and a day restores one day's worth: the village pays the full price for three crates of berries and two of each meat a day before food prices slowly slip, while every steel tool sold lowers its price sharply and about a crate of each a day keeps them steady ([docs/ECONOMY.md](docs/ECONOMY.md)); buying costs a fixed 1.25× the base price, so a buy-and-resell loop never profits. The Workers tab offers several hiring deals: more coins up front means a lower daily wage. Workers are individual entities with assignments, wages, cargo, and visible work status. They break for an hour of lunch at noon, sitting around the campfire closest to the crew, walk to the nearest signpost as dusk falls and head off down the valley like a trade cart, fading from view, then walk back in the same way at dawn; assignments and anything they carry stay as they were. While they are away a forge cools and an anvil stops. An unpaid worker strikes, and owed wages stop growing until the strike is settled. Storage input filters govern automated deposits; output filters govern worker withdrawals. Empty filters allow all items. Workers prefer explicitly accepting chests and reroute cargo when filters change. Manual inventory transfers ignore these automation filters.

Fog of war covers the map. Ground you have never seen is black. You see live only within a circle around you (`sightRadius` in `data/game.json`, 20 tiles), which fills the screen at full zoom-out. Ground you have seen before is greyed out and shows things as you last saw them: a tree felled out of sight still stands there until you look again. Remembered fires and furnaces show unlit, and wolves, workers and carts are not shown. Explored ground and remembered things are kept in saves.

The world is a fixed 216×216-tile valley. It opens onto the sea at the bottom of the screen, which cannot be drunk and is the map's edge; impassable mountain ranges close in from the left and right toward the valley's inland end, and a lake lies in the middle. The plains have occasional rocks, bushes and berry bushes, and the trees thicken into woods toward the mountains, so finding more means going out to look. Iron and coal deposits sit at the foot of rock faces at the base of both ranges and need a pickaxe; loose coal is scattered below the nearer coal face and is picked up whole with one right-click, with no tool. Saves from the earlier, smaller maps cannot be loaded. Trade carts keep their timing: a cart walks down the valley at a steady pace, fades out once it is well along, and waits out of view before walking back. Errand runners only walk a short way down the valley before fading from view. Workers use simple grid detours around water and buildings; this is not a full navigation system. Player and worker actions use a jointed 3D rig with keyframed poses for idling, walking, hand gathering, axe and pick strokes, hammering, bellows pumping, crate carrying, sitting at lunch (cross-legged on the ground or on a rock) and an unarmed punch. Player tool actions follow the carried tool, while worker actions follow explicit transient work state rather than display text. The world reacts too: trees shake and topple into stumps, deposits shrink and throw chips, the bellows board travels with each press, the heat gauge tracks the forge, a bar under the bellows furnace and its panel gauge mark the clear bar steel needs, furnaces smoke (the bellows furnace darker and thicker), anvils spark, storage lids open on transfers, the cabin door opens as you approach, the market mailbox flag rises while a cart is out, wolves trot, leap, feed and fall dead, a pinned player struggles on their back, and couriers pull the trade cart. Animations pause with gameplay. Sound effects follow the same actions: footsteps change on grass, rock and the lake shore, axes, anvils and swings have impacts, fires crackle as they catch, including a furnace lighting a new batch, and wolves growl from afar, growl again as they close in and bite. Day and night have their own music, which crossfades as the time changes and picks up where it stopped last time; Options has a music volume slider. Repeated sounds rotate between variants. Sounds on screen play at full volume and fade out just past its edge, so zooming out lets you hear further. Trees in front of the player, a worker or a structure turn see-through. Worker automation is limited to gathering and station/furnace tasks, with at most eight workers. There is no charcoal system, pollution, vampire threat, or technology beyond steel in this POC.

The environment uses a shared human scale, low-poly mountain ranges, a sandy shore and sea, an irregular lake with reeds and lily pads, a grass valley with scattered tufts, bushes and wildflowers, a worn trail down to the shore, and three tree types (oak, spruce, birch). Workers wear blue bib overalls, cream shirts and yellow hard hats; the player wears a teal T-shirt, jeans and a daypack. Night is lit by the sun, ambient light and real fire light from campfires, furnaces and cabin windows.
